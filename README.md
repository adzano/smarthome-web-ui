# Smart Home Web UI

Dashboard statis untuk Smart Home. UI ini memakai backend pada `http://127.0.0.1:8000` saat pengembangan lokal.

Jalankan backend terlebih dahulu, lalu buka `index.html` dengan static server pada port 5500 agar browser dapat mengakses API. Contoh:

```sh
python3 -m http.server 5500
```

Buka `http://127.0.0.1:5500` dari browser Mac. Dukungan akses langsung dari iPhone pada jaringan lokal akan ditambahkan saat backend dipasang pada perangkat yang selalu menyala.
